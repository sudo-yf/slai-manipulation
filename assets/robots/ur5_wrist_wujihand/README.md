# UR5 + Wrist + Wujihand (Right)

The simulation asset is defined by:

```text
ur5_wrist_wuji_right.urdf
```

Its 28 movable degrees of freedom are:

- UR5 arm: 6 revolute joints
- Wrist: 2 revolute joints
- Wujihand right hand: 20 revolute joints

The `meshes/` directory is required by the URDF and must remain beside it.
